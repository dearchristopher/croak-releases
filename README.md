# Croak releases

Installers and the update feed for Croak. The source lives in a private repo.

## Install

Download the latest release from [Releases](https://github.com/dearchristopher/croak-releases/releases/latest):

- **Windows:** `Croak_<version>_x64-setup.exe`
- **macOS:** `Croak_<version>.dmg`

Croak checks this repo for new versions and offers to update itself from inside the app.
